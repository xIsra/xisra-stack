# xisra-stack

Reusable [agent skills](https://agentskills.io) by [Israel Kouperman](https://xisra.com).

Install with the [skills CLI](https://skills.sh):

```bash
npx skills add xIsra/xisra-stack
```

Install a single skill:

```bash
npx skills add xIsra/xisra-stack --skill explain-flow
```

## Skills

| Skill | Description |
| --- | --- |
| [explain-flow](skills/explain-flow/SKILL.md) | Use when explaining complex data flows, pipelines, or multi-step code paths. |
